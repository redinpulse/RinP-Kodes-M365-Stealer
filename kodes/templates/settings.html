Global Settings

These values are written to server.json. Campaign-level values (target domain, auth site) take precedence in the campaign record; empty fields are filled with these global values.

Devices without a campaign-specific domain use this domain. Values outside DNS format are rejected.

Recommended default for new campaigns and config downloads.

If set, it is embedded in the campaign's client.json download — the downloaded file can be used directly on the target. If empty, the downloaded config keeps null and the target's existing client.json value applies.

Notlar

  • The domain is validated with a DNS regex at save time; only validated values enter the PowerShell command line.
  • The file path can be overridden with the KODES_SERVER_CONFIG environment variable.
  • The config cache is reset automatically after saving — no service restart is needed for values to take effect.
